# Desktop Pet 使用指南

你现在有三种方式跟桌宠聊天。

---

## 方式一：桌面 GUI（一直有的）

**怎么用：**
1. 双击桌面快捷方式，或终端输入 `npm start`
2. 屏幕右上角出现一只猫
3. 点击猫 → 弹出聊天窗口
4. 打字 → 回车发送 → AI 回复

**适用场景：** 坐在电脑前，想跟猫聊天。

---

## 方式二：手机微信（刚做的）

**前提条件：** 电脑开着桌宠（`npm start`），手机微信里有 ClawBot。

**首次设置（只做一次）：**
1. 电脑上启动桌宠
2. 点击聊天窗口右上角 ⚙️ → 设置面板
3. 找到"📱 微信接入 (ClawBot)" → 打开开关
4. 出现黑白二维码
5. 打开手机微信 → 扫一扫 → 扫描这个二维码
6. 手机上点"确认"
7. 设置面板显示"● 已连接到微信"

**平时使用：**
1. 手机打开微信
2. 找到 ClawBot 联系人
3. 发消息过去
4. 等几秒 → AI 回复出现在微信里

**【注意】重启电脑后：**
-  桌宠会自动重新连接（前提是你上次没关微信开关）
-  如果连不上，打开设置面板 → 点"🔄 重新连接" → 重新扫码

**适用场景：** 人在外面，电脑开着，用手机操控桌宠。

---

## 方式三：终端 / 命令行（刚做的）

**前提条件：** 电脑开着桌宠（`npm start`）。命令行和桌宠是**两个窗口**，不能关掉桌宠只用命令行。

### 单次提问（问一句就走）

```bash
# 打开一个新终端窗口，输入：
node cli.js "今天天气怎么样"
```

电脑会显示一个旋转动画，然后打印 AI 回复。回复完就结束。

### 连续聊天（交互模式）

```bash
# 打开一个新终端窗口，输入：
node cli.js
```

会出现：

```
  ╔══════════════════════════════╗
  ║   🐱 Desktop Pet CLI        ║
  ║   输入消息开始聊天            ║
  ║   /exit  退出               ║
  ║   /new   新建对话            ║
  ╚══════════════════════════════╝

🐱 >
```

然后你就可以一直敲字聊天了：

```
🐱 > 帮我写一个排序
      （AI 回复...）

🐱 > 能改成倒序吗
      （AI 回复...）

🐱 > /new          ← 开启新话题
🐱 > /exit         ← 退出
```

### 管道输入（喂文件给 AI）

```bash
# 让 AI 帮你分析日志
cat error.log | node cli.js "这段日志出了什么问题"

# 让 AI 读代码
cat main.js | node cli.js "解释这段代码"

# Windows PowerShell 里用：
Get-Content error.log | node cli.js "分析一下"
```

### curl 调用（写脚本用）

```bash
curl -X POST http://127.0.0.1:9876/chat \
  -H "Content-Type: application/json" \
  -d '{"message":"你好"}'
```

**适用场景：** 坐在电脑前但不想点鼠标，或者想写脚本自动化。

---

## 三个方式的关系

```
           方式一：GUI            方式二：微信             方式三：终端
          桌面窗口聊天            手机扫码聊天              命令行聊天
                │                    │                       │
                └────────────────────┼───────────────────────┘
                                     │
                             同一个 AI 引擎
                           （共享对话历史、API Key、设置）
```

- **共享对话**：不管用哪个方式说，AI 都记得之前说过的话
- **共享设置**：API Key 和模型设置在 GUI 里配一次，三个方式都能用
- **必须开着桌宠**：三个方式都依赖电脑上运行的桌宠进程

---

## 常见问题

**Q: 能只开终端不用 GUI 吗？**
A: 不行。桌宠 GUI 必须启动（`npm start`），它负责运行 AI 引擎。终端只是多了一个**入口**。

**Q: 微信连不上怎么办？**
A: 打开设置面板，关掉微信开关再打开，重新扫码。

**Q: 终端执行 `node cli.js` 报错"无法连接"？**
A: 说明桌宠没启动。先开一个新终端执行 `npm start`，再用另一个终端用 `cli.js`。

**Q: 手机在外面，怎么保证电脑开着？**
A: 出门前别关电脑就行。桌宠启动后常驻后台（托盘图标），不会被误关。

**Q: 能不能在手机上用终端方式？**
A: 可以，但需要内网穿透（如 Tailscale、frp）。手机连到电脑内网后，浏览器访问 `http://电脑IP:9876/chat` 或用 SSH 客户端执行 `cli.js`。
